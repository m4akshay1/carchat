# CarChat

A chat page where a dealership sales manager asks questions about vehicle inventory in plain English and gets answers computed from a database, never from the model's memory. Every answer shows the SQL that produced it and the rows it returned.

**The data is not a real dealership's inventory.** Vehicle year, make, model and class come from the public EPA fuel economy dataset; prices, costs, mileage, stock numbers and lot dates are generated.

Created in 30 min. Testing and personal changes next
